# Customer-Behaviour-Analysis
Data Analytics Project
📌 Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data loading to insights presentation. It covers data exploration, cleaning, SQL analysis, dashboard creation, and final reporting using industry-standard tools.
The goal is to extract meaningful insights and present them clearly for business decision-making.

📁 Dataset

Source: Provided / Public dataset (CSV format)
Data Type: Structured data
Description: Contains business-related records used for analysis and visualization
(Dataset details can be updated based on your project)

🛠 Tools & Technologies

Python – Data loading, cleaning, and EDA
Libraries – Pandas
MySQL – Data storage and SQL queries
Power BI – Interactive dashboard creation
Gamma – Report and presentation (PPT) creation

🔄 Project Steps

Data Loading
Imported dataset into Python using Pandas
Performed initial data inspection
Exploratory Data Analysis (EDA)
Checked data structure, missing values, and distributions
Identified trends, patterns, and anomalies
Data Cleaning
Handled missing and duplicate values
Corrected data types and standardized formats
SQL Analysis (MySQL)
Loaded cleaned data into MySQL
Executed SQL queries for deeper analysis and aggregations
Dashboard Development
Built an interactive Power BI dashboard
Visualized KPIs, trends, and comparisons
Reporting & Presentation
Created a detailed analytical report
Designed a professional PPT using Gamma

📈 Dashboard

The Power BI dashboard includes:
Key performance indicators (KPIs)
Trend analysis
Category-wise and time-based insights
Interactive filters for better exploration

📊 Results & Insights

Identified key patterns and trends in the data
Highlighted actionable insights for stakeholders
Converted raw data into clear, visual, and business-friendly outputs

▶️ How to Run the Project

Clone the repository
Install required Python libraries
Run the Python scripts for data loading, EDA, and cleaning
Import the cleaned dataset into MySQL
Execute SQL queries provided in the SQL folder
Open the Power BI file to view the dashboard
Review the report and presentation created using Gamma

This project highlights practical skills in data analysis, SQL querying, visualization, and reporting, making it suitable for real-world business analytics roles and recruiter evaluation.
